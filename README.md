# Supercar World

One-page site: header, about, collection (projects), contact.
Files: index.html, style.css, app.js, images/

## Publish on GitHub Pages
1. Create a repository named yourname.github.io and upload all files (keep the images folder).
2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. After a minute your live link is https://yourname.github.io (HTTPS is on by default).

Common errors: wrong file paths (keep images/ next to index.html) and Pages not enabled.
