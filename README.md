# Supercar World

One-page site: header, about, collection (projects), contact.
Files: index.html, style.css, app.js, images/, logos/

## Upload to GitHub (whole folders, not one by one)
1. Create a repository (for GitHub Pages: yourname.github.io).
2. Click "Add file" > "Upload files".
3. Select index.html, style.css, app.js, README.md AND the images and logos folders,
   then drag them all into the page at once. GitHub keeps the folders.
   (Limit: 100 files per upload. This project has about 35, so one upload is enough.)
4. Click "Commit changes".

## Publish on GitHub Pages
1. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
2. After a minute your live link is https://yourname.github.io (HTTPS is on by default).

## Replace the placeholder logos
logos/ holds placeholder gold-letter logos. Replace each with the real logo using the
same filename (ferrari.png, lamborghini.png, mclaren.png, porsche.png, bugatti.png,
koenigsegg.png). You can drag the whole logos folder in again to overwrite them.

Common errors: wrong file paths (keep images/ and logos/ next to index.html) and Pages not enabled.
